The test

Same prompt, two models

I gave Claude Opus 5.5 and Claude Fable 5.2 the same prompt in Claude Code: a website for a design studio. Both used my own /awwwards design skill.

What happened
Opus 5.5Done first: 7.2 min, $2.14. The hero and pricing looked good, but the six project pictures never appeared.
The fixOne message in the same chat. Fixed in one try: about 45 s on my clock (39.2 s in its log), +$0.22.
Fable 5.2Every picture on the first try: 8.4 min, $3.70.
TotalOpus with its fix: $2.36. Fable: $3.70.

Costs are Claude Code's own figure at API list prices, an estimate, not a plan bill. Claude Code 2.1.322, 10 Nov 2026.

Step 1

The prompt

Paste it into Claude Code as it is, or swap in your own business.

Copy this prompt
Build a website for my design studio, Halfmoon Studio. We're a 3-person studio in Pune that designs brands and websites for small businesses.

One page with:
- a hero with our name and one line about what we do
- 6 selected projects in a grid (make the project images yourself with CSS or SVG, no stock photos)
- our services, with prices starting at ₹25,000
- a short about section with the team
- a contact form

Make it look like a real studio's website: a strong layout, smooth scroll animations, and real copy (no lorem ipsum).
It must work on a phone too.

Use plain HTML, CSS and JavaScript in this folder. No build step and no libraries, except Google Fonts.
When it's done, open index.html in my browser.
Make it yours

Change the studio name, the city, what you do and the starting price. Keep "real copy (no lorem ipsum)" and "It must work on a phone too": they're why the site looks finished.

2

The fix message

Opus said the site was built. Then I scrolled to Selected work: the space stayed empty, only the text showed. I sent this in the same conversation:

The exact message I sent
This is broken: when I scroll down to Selected work, the project pictures never show up. The space stays empty, only the text appears. Fix it without changing anything else.

Fixed in one try: about 45 seconds, +$0.22 at API prices.

Before you send it to anyone

How to spot this kind of bug

  • Scroll every section, slowly. The first screen of Opus's site looked done. The bug only showed further down.
  • Stop and wait at each section. Scroll animations should finish in a second or two. A box that stays empty is broken.
  • Check it on your phone, not just a narrow window. The prompt asks for it, so test it.
  • Open it in a second browser. The missing pictures were a Chrome problem: the reveal animation never fired there.
  • Reload and scroll fast once. Animations that start on scroll are the usual ones to break.
Why it broke

Each project picture was hidden behind a clip-path reveal, an animation that's meant to uncover it as you scroll to it. In Chrome it never fired, so the pictures stayed hidden while the text showed.

Your own fix message: fill in the brackets
This is broken: when I [what you did], [what should happen] never [happens]. [What you see instead]. Fix it without changing anything else.
When to use which

Opus or Fable?

Opus 5.5Your everyday model, and the default in Claude Code. $4 / $20 per million tokens (input / output). Anthropic calls it "our strongest daily driver".
Fable 5.2For the big, open-ended jobs where getting it right the first time matters. $8 / $40: exactly 2× Opus per token.
My ruleUse Opus, but check its work before you send it. Scroll everything, then send one clear fix message.
Reach for FableWhen one fix doesn't do it, or when the job is too big to keep checking.

One run each. A second Opus run of the same prompt without my skills got every picture right ($1.51, 5.2 min), so treat this as one test, not a law.

Switch models in Claude Code

  • Fable 5.2 needs Claude Code 2.1.321 or later (claude --version, then claude update).
  • Type /model fable to switch, and /model opus to go back.
  • /usage shows a session's tokens and its cost at API prices.
