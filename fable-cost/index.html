The test

Same job, two models

Claude Fable 5.2 came out on 9 Nov 2026 and costs twice as much per token as Opus 5.5. So I gave both the same real job: a website for a small design studio.

How I ran it

  • Claude Code, one prompt, one try each. No follow-ups, no fixes.
  • Opus 5.5 worked by itself. No skills: I blocked them for this run.
  • Fable 5.2 picked my design skill, /awwwards, on its own. It's a skill I wrote for myself, so it's not something you can install.
  • Each run started in an empty folder, on 10 Nov 2026.
Read the costs right

The dollar figures are what Claude Code reports for the session at API list prices. They're an estimate of the work, not what my plan billed me.

The short answer
Opus 5.55.2 min · $1.51
Fable 5.28.4 min · $3.70
VerdictFor a website like this, Opus by itself is enough
The prompt

The exact prompt I used

Paste it once into each model, in its own empty folder. Then don't touch it.

Copy this prompt
Build a website for my design studio, Halfmoon Studio. We're a 3-person studio in Pune that designs brands and websites for small businesses.

One page with:
- a hero with our name and one line about what we do
- 6 selected projects in a grid (make the project images yourself with CSS or SVG, no stock photos)
- our services, with prices starting at ₹25,000
- a short about section with the team
- a contact form

Make it look like a real studio's website: a strong layout, smooth scroll animations, and real copy (no lorem ipsum). It must work on a phone too.

Use plain HTML, CSS and JavaScript in this folder. No build step and no libraries, except Google Fonts. When it's done, open index.html in my browser.

Worth it?

When Fable is worth 2×

Anthropic's own advice

For most coding and knowledge tasks, start with Opus 5.5, "our strongest daily driver". Fable is "best for the most ambitious, open-ended technical work".

Use Opus 5.5 for

  • Everyday builds like this website, landing pages, small apps
  • Edits, fixes and anything you'll run many times a day
  • Anything where a good result now beats a perfect one later

Try Fable 5.2 for

  • The hardest, open-ended jobs: big builds, tricky systems
  • A problem Opus has already tried and couldn't crack
  • Work where one better answer is worth paying double for
My take
Opus by itself is enough

For a website like this one, both looked like a real studio made them. I'd keep Fable for the hard jobs.

Run it yourself

Check the cost yourself

1

Update Claude Code

Fable 5.2 needs version 2.1.321 or later. Check with claude --version.

2

Run Opus first

Open Claude Code in an empty folder, type /model opus, paste the prompt and let it finish.

3

Read the cost

Type /usage (or /cost). It shows the session's tokens and cost at API prices: an estimate, not your bill. On a plan you also see your usage bars.

4

Run Fable the same way

New empty folder, /model fable, the same prompt, then /usage again. Compare the two numbers and the two sites.

Before you switch

Where Fable bills to usage credits (Pro after 16 Nov), the model menu says "Requires usage credits" and asks you to agree once. That's real money.

Spend where it counts

Opus for the everyday, Fable for the hard ones.
