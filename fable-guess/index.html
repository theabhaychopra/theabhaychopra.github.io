The answer

Which one was Fable?

Same prompt, Claude Code, one try each, no fixes. Here's who built what.

About /awwwards

It's a design skill I wrote for myself in Claude Code. Fable chose to use it on its own. For Opus, I blocked skills, so it worked with the prompt alone. You can't install mine, but any skill of yours works the same way.

The prompt

The prompt behind both

Word for word what both models got. Nothing else.

Copy this prompt
Build a website for my design studio, Halfmoon Studio. We're a 3-person studio in Pune that designs brands and websites for small businesses.

One page with:
- a hero with our name and one line about what we do
- 6 selected projects in a grid (make the project images yourself with CSS or SVG, no stock photos)
- our services, with prices starting at ₹25,000
- a short about section with the team
- a contact form

Make it look like a real studio's website: a strong layout, smooth scroll animations, and real copy (no lorem ipsum). It must work on a phone too.

Use plain HTML, CSS and JavaScript in this folder. No build step and no libraries, except Google Fonts. When it's done, open index.html in my browser.

The question
Which one would you pay double for?

Fable costs exactly 2× Opus per token. Anthropic itself suggests Opus 5.5 for most work and Fable for "the most ambitious, open-ended technical work".

Your turn

Run the same test

1

Update Claude Code

Fable 5.2 needs version 2.1.321 or later (claude --version). How models work in Claude Code: code.claude.com.

2

Two empty folders

Make one folder per model, so neither sees the other's site.

3

Opus in the first

Open Claude Code there, type /model opus, paste the prompt. One try: don't fix anything.

4

Fable in the second

Type /model fable, paste the same prompt. Again, one try.

5

Compare

Open both index.html files, on your laptop and your phone. Type /usage in each session to see its cost at API prices.

Keep it fair

Skills change the result. Run both without skills, or give both the same one. On Pro, Fable is included only until 16 Nov 2026, 11:59 pm PT; after that it runs on paid usage credits. Prices and plans: anthropic.com/claude/fable.
