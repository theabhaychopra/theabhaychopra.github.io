The prompt

Copy it as it is

Copy this prompt
Build me an invoice app for my freelance work. It runs in the browser from this folder: plain HTML, CSS and JavaScript, no build step. Save everything on my laptop (localStorage). No accounts, no servers.

- My details, saved once: name, address, GSTIN (optional), bank and UPI details
- Clients: name, address, state, GSTIN (optional)
- An invoice: number (automatic), date, due date, line items (description, quantity, rate in ₹), subtotal
- GST: a rate field (default 18%) with an on/off switch. Show CGST + SGST when the client is in my state, and IGST when they're in another state
- The total in ₹, in numbers and in words
- A "Download PDF" button that saves a clean A4 invoice
- A list of past invoices, each marked paid or unpaid

When it's done, open it in my browser.

How to run it

Four steps in Claude Code

  • Update Claude Code. Fable 5.2 needs version 2.1.321 or later (claude --version).
  • Open it in an empty folder — the app is built there.
  • Type /model fable to switch. /model opus switches back; Opus 5.5 stays the default.
  • Paste the prompt and let it work. It opens the app in your browser; add your own details first.
Before a real invoice

Read this first

Not tax or legal advice

This is an app an AI built for me, not an accounting product. Check the GST rules for your work with a CA before you send a real invoice. If you're not registered for GST, switch it off.

Your data stays in your browser

Everything is saved in your browser's localStorage on your laptop — no accounts, no servers. Clearing your browsing data deletes it, so keep a backup. (Mine added a "Save a backup file" button.)

Try Opus first

Opus 5.5 costs half as much per token as Fable. I ran this prompt on Fable, so I can't promise Opus gets the same result — but it's the cheaper first try: type /model opus instead.
