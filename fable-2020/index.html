Before you start

What you need

  • Claude Code, version 2.1.321 or later. Run claude update, then check with claude --version (claude.com/claude-code)
  • Fable 5.2: type /model fable inside Claude Code. /model opus switches back to Opus 5.5, which stays the default
  • A paid Claude plan: Fable is on Pro, Max, Ultra, Team and Enterprise, not Free (the costs are in "What it costs")
  • Your old website's folder: the HTML, CSS, images and other files, on your computer
What I did

I gave Fable 5.2 the folder of the site I made in 2020 and one prompt. I started it with /awwwards, my own design skill. No follow-ups: everything you see came from that one message.

Step 1

Prepare your folder

1

Make a copy of your site's folder

Duplicate the whole folder and work only in the copy. Your original stays untouched, whatever happens. I used a copy without the .git folder, so nothing could be pushed to my live site by accident.

2

Open Claude Code inside the copy

In your terminal
cd my-site-copy
claude

Then type /model fable and press Enter.

3

Paste the prompt

It's in the next section, "The prompt". The prompt itself asks for a new folder called redesign/, so your old files stay exactly as they are, even inside the copy.

Tip

If your site has many pages, ask for the home page first, then say "do the same for the other pages".

Step 2

The prompt

Word for word, the prompt I used in the reel.

Copy this prompt
/awwwards This folder is my website from a few years ago. Redesign it so it looks like a website made in 2026.

Keep every word of my content, my name, my links and my photos. Don't invent anything new about me. Change only the design: layout, fonts, colours, spacing and animations. It must work well on a phone.

Keep it plain HTML, CSS and JavaScript, with no build step. Put the redesigned pages in a new folder called redesign/ so my old files stay exactly as they are. When it's done, open redesign/index.html in my browser.
About /awwwards

/awwwards is my own design skill for Claude Code, so you won't have it. Delete that first word and send the rest. I ran this same prompt without it too: 8.8 minutes, $5.12, a simpler dark design that kept the same words, photo and sections.

Why each line is there

  • "Keep every word… don't invent anything" stops it from writing new claims about you
  • "Change only the design" tells it what it may touch
  • "Plain HTML, CSS and JavaScript, no build step" means you can open the result straight away
  • "A new folder called redesign/" keeps your old pages safe next to the new ones
What it made

Every word, a new design

The ideamy signature logo inside a code tag, "< Abhay Chopra />". Its brackets frame the menu, buttons and headings
Pagesredesign/index.html, journey.html and a 404 page
Contentmy words, photo and posters, all kept
Phonesthe Journey page now works on phones (in 2020 it said "Desktop Only")
What it told me it changed

Besides the design, three things: callto: links became tel: links (so a tap opens the phone dialler), an empty Calendly button became a real link, and the Journey page now works on phones. It flagged each one at the end of the run, so I could check them.

Step 3

What to check after

  • Every word. Read the old page and the new one side by side. Nothing should be missing, and nothing new should be made up about you.
  • Every link. Click each one, and check where it goes now. Look hardest at any link it says it changed (mine: callto: → tel:, and the Calendly button).
  • Your phone number and email. Tap them on a real phone.
  • On a phone. Open redesign/index.html on your phone, or in your browser's phone view, and scroll every page.
  • Your photos. They should be yours, not new ones.
A check prompt (my suggestion)
Compare every word in my old pages with the pages in redesign/. List anything missing, changed or added. Then list every link and phone number in redesign/ and where each one goes.
Only then

Replace your live site only when every check passes. Keep the old folder as a backup.
