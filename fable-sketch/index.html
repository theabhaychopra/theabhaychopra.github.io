Before you start

What you need

  • Claude Code, version 2.1.321 or later. Run claude update, then check with claude --version (claude.com/claude-code)
  • Fable 5.2: type /model fable inside Claude Code. /model opus switches back to Opus 5.5, which stays the default
  • A paid Claude plan: Fable is on Pro, Max, Ultra, Team and Enterprise, not Free (the costs are in "What it costs")
  • A pen, paper and your phone's camera
  • An empty folder on your computer for the new site
What I did

I drew a website on my notepad, took one photo and gave it to Fable 5.2 with one line of text. I started it with /awwwards, my own design skill. No follow-ups.

Step 1

Draw a sketch Claude can read

  • One page = one screen. Draw a frame for the edge of the page first.
  • A box for each part: the logo, a picture, a row of cards. Three boxes means three things.
  • Label what isn't obvious with one word, like I wrote "Logo". Short notes work too: "button here", "make this blue".
  • Draw the things that matter. My sun, mountains and bike all became part of the design.
  • Take the photo from above, in good light, with the whole page in the frame.
Step 2

The prompt

1

Open Claude Code in an empty folder

In your terminal
cd my-sketch-site
claude

Then type /model fable and press Enter.

2

Send the photo with one line

This is exactly what I typed. Drag your photo into Claude Code where it says [your photo]: it pastes the file's path for you.

The prompt I used
/awwwards build this: [your photo] (plain HTML, CSS and JS in this folder, no build step)

"Plain HTML, CSS and JS, no build step" means you can open the result in your browser straight away.

About /awwwards

/awwwards is my own design skill for Claude Code, so you won't have it. Without it, use the fuller prompt in the next section, "Without my design skill".

No skill needed

Without my design skill

My suggestion for a plain prompt. I haven't tested this one: it spells out what my skill did for me.

A fuller prompt (not tested)
[drag the photo of your sketch in here]

Build this as a website. Every box on my sketch is a section, in the same order. Follow my handwritten notes in the margins too.

Make it look finished: real copy instead of placeholder text, a clear layout, and it must work on a phone. Use plain HTML, CSS and JavaScript in this folder, with no build step. Open it in my browser when it's done.

Make it yours

  • Say what it's for. Mine had no name and no text, so it invented a business. If you want your own name and words, add them: "It's for my bakery, [name], in [city]."
  • Ask for one change at a time after the first build: "make the bike bigger", "add a contact form".
  • Open it on your phone before you call it done.

What it added

It gave it a name

My sketch had no name and no text. It called the site Lacet ("Guided cycling climbs in the French Alps") and wrote all the copy. It added a day timetable, a footer, a 404 page, and three climb pages where the bike rides the climb with live km, altitude and gradient. There are no photos: the maps are drawn in code.

Check it yourself

In my run, its own browser checks were blocked, so the finished site was checked afterwards in a real browser. Open yours and scroll every page before you share it, on your phone too.
