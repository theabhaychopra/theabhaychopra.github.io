The steps

Switch to Fable in two commands

1

Update Claude Code

In your terminal
claude update
claude --version

Fable 5.2 needs version 2.1.321 or later (out on 9 Nov). Mine went from 2.1.198 to 2.1.322.

2

Switch the model

Inside Claude Code
/model fable

Type it inside Claude Code. Or start with claude --model fable. /model opus switches back to Opus 5.5, which stays the default.

See what a session used

/usage shows the tokens and a cost worked out at API prices. On a Pro or Max plan that's an estimate, not your bill.

Which plan gets it

On Pro, the date that matters

Freeno Fable
Pro + standard Teamall Fable models included until 16 Nov 2026, 11:59 pm PT: up to 50% of your weekly limits, plus one Fable limit reset. After that, Fable runs on usage credits, which you pay for.
Max, Ultra, premium seatsincluded, up to 50% of your weekly limits, plus 1–3 launch resets (by how long you've subscribed) that last until 8 Mar 2027
After the 16th, on Pro

The /model picker shows "Requires usage credits" next to Fable and asks you to agree once before it uses them.

My tip

Use Fable for big, hard jobs. Keep Opus for everyday work and switch back with /model opus. Anthropic says the same: start with Opus 5.5 for most coding, and use Fable for "the most ambitious, open-ended technical work".

My first Fable job, at API prices
$3.70

One prompt, 8.4 minutes, a whole website (the next section). Claude Code's own estimate at list prices, not my plan bill.

First thing to try

My prompt: a whole studio website

Copy this prompt
Build a website for my design studio, Halfmoon Studio. We're a 3-person studio in Pune that designs brands and websites for small businesses.

One page with:
- a hero with our name and one line about what we do
- 6 selected projects in a grid (make the project images yourself with CSS or SVG, no stock photos)
- our services, with prices starting at ₹25,000
- a short about section with the team
- a contact form

Make it look like a real studio's website: a strong layout, smooth scroll animations, and real copy (no lorem ipsum). It must work on a phone too.

Use plain HTML, CSS and JavaScript in this folder. No build step and no libraries, except Google Fonts.
When it's done, open index.html in my browser.
Make it yours

Start Claude Code in an empty folder, type /model fable, paste the prompt. Swap in your own studio, city and prices.
