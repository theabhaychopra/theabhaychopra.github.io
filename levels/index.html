Part 1

The about-me file

Fill in the brackets once. Claude reads it before every answer.

Where it goes
Freethe Claude app: Settings › Your Claude › Instructions. Paste it there.
ProClaude Code or Cowork: save it as CLAUDE.md in ~/.claude/ (every project) or in one project folder. /init writes a starter, /memory edits it.
Copy this: the about-me file
# About me
Name: [your name]
What I do: [e.g. I make Instagram reels about AI tools for Indian creators]
Who it's for: [your audience in one line]

# How I write
- Short sentences. Plain words. Talk like a friend, not a brand.
- [one more rule you always follow]
- Never use: [words you hate, e.g. "unlock", "game-changer"]

# How to work with me
- If the task is unclear, ask me one question first.
- When I ask for ideas, show me 3 options.
- Before a big change, tell me the plan.

# Examples of my best work
- [paste 2 real posts you're proud of]
Part 2

The my-voice skill

A skill is a saved how-to that Claude follows every time. This one writes in your voice.

1

Turn on file creation

Settings › Capabilities › Code execution and file creation (in the new layout: Create and edit files).

2

Make the folder

A folder called my-voice with the file below saved as SKILL.md, plus 3 of your own posts saved as examples.md.

3

Upload it

ZIP the folder (one skill per ZIP). Customize › Skills › + › Create skill › Upload a skill. In Claude Code (Pro): put it in ~/.claude/skills/my-voice/ and type /my-voice.

Copy this: SKILL.md
---
name: my-voice
description: Writes or rewrites posts, captions and scripts in my own voice. Use whenever I ask for content I'll publish.
---
# Write in my voice
1. Read examples.md first: 3 posts I wrote myself.
2. Match their sentence length, tone and the way they open.
3. Plain words. Nothing from my "never use" list.
4. Give me 3 different versions, then say which one you'd pick and why.
5. Before you answer, check your draft against steps 2-4 and fix it.

From India

Instead of Duet

Claude Duet is a US-only waitlist for now. On Pro you can get a morning brief today: connect Gmail and Google Calendar (Customize › Connectors), then paste this into a chat and click Schedule.

Copy this: your morning brief
Every weekday at 8 AM, read my new email and today's calendar. Send me the 3 things I should do first, and draft replies for anything urgent. Don't send anything.

Before you install anything

  • Official: github.com/anthropics/skills, and plugins marked Anthropic verified in Customize › Plugins.
  • Community: plugins like superpowers (by Jesse Vincent, github.com/obra/superpowers) are made by other people. Read a skill's SKILL.md before you upload it: it's plain text.
  • Never paste passwords, API keys or bank details into a chat, a skill or the about-me file.
