The link

Harvey

Instead of lead tools at $250–500/mo → $0

An open-source sales agent that runs on your Claude Pro or Max plan through Claude Code. It finds businesses that fit what you sell, reads their websites, writes each one a personal cold email and works the replies toward a meeting.

Free limitNo API key and no per-token bill: model calls use your Claude plan. Harvey caps itself at 80 % of your daily usage, and nothing is sent until you approve it.
Runs onYour own computer (Mac, Linux or Windows with Claude), in a loop every 15 minutes. You need your own mailbox to send from.
Paid still winsBig companies and huge contact lists. Harvey is strongest on small local businesses, read from their own websites.
Client workMIT, made by Ethan+ (ethanplusai on GitHub).
Start in 3 steps
  1. Open the repo and read the first screen of the README.
  2. Follow "Setup in one sentence" on the next section.
  3. Keep approval on for your first batch.

Before you start

What you need

The honest cost list
Claude Pro or Maxthe plan you already pay for, logged in to Claude Code (claude login)
Python 3.11+free. On a Mac: brew install python@3.13 (macOS ships 3.9)
A mailboxGmail / Google Workspace (~$7 a month) or Microsoft 365, ideally on a separate sending domain
Finding businesses$0 on the default source (OpenStreetMap). Paid sources are optional, from ~$0.37 per 1,000
Reading their sites$0: three web requests each, no AI call
So is it free?

The code is free and open source, and there's no API bill. You still need a Claude plan and a mailbox. Everything else is optional.

The easy way

Setup in one sentence

Copy this prompt
git clone https://github.com/ethanplusai/harvey.git
cd harvey
claude

Claude Code opens inside the Harvey folder. Then type this one sentence:

Copy this prompt
set up Harvey for me
What happens

The repo ships a CLAUDE.md that turns Claude Code into the setup wizard. It checks what's installed, installs what's missing, asks what it needs (your website, your mailbox) and trains Harvey on your product.

Or by hand

Six commands

Copy this prompt
python3.13 -m venv .venv && source .venv/bin/activate && pip install -e .
cp .env.example .env
harvey train https://your-site.com
harvey signals --confirm free
harvey discover
harvey dashboard
harvey run
What each one does
installa Python 3.13 environment with Harvey in it
.envadd your mail provider; every line says where to get it
trainreads your site: what you sell, who you sell to
signalsturns on the 26 free facts that make an email personal
discoverfinds businesses (free source, no account)
dashboardprints a private link to 127.0.0.1:5555
runthe loop: every 15 minutes
Day one

Your first run

1

Train it on your real site

harvey train writes what you sell and who you sell to. Fix anything it got wrong before you go on.

2

Pick the signals

The facts that make an email personal: no online booking, running Google Ads, the agency in their footer, a role they're hiring for. Start with the free ones.

3

Estimate before you pay

harvey discover --estimate shows what a paid source would cost before it spends anything.

4

Read the first batch in the Outbox

Every email waits for you: A approve, R reject, E edit. Keep approval on until you trust what it writes.

Stop everything

Type harvey sending pause in the terminal: it stops all sending at once, even mid-cycle.

Read this first

Before you send a single email

  • You are the sender. Every cold email ends with an opt-out line. Set your postal address (compliance.postal_address) before your first campaign; Harvey adds both.
  • EU / UK: business cold email needs a real reason that person would care (legitimate interest). If you can't say why, don't send.
  • If someone asks "is this AI?", Harvey says yes. Leave that setting alone.
  • Warm up first. A new sending domain needs SPF, DKIM and DMARC (harvey warmup checks them), then 2–4 weeks at 10–20 emails a day, adding about 5 a day.
  • Watch bounces. Above about 3 %, stop and clean the list. Harvey trips its own kill switch past your limit.
Not legal advice

Sending at volume or into regulated industries? Ask a lawyer where you live.

Stuck?

If something breaks

command not found: harveyrun source .venv/bin/activate first
odd errors after install (Mac)your venv is Python 3.9: rebuild it with python3.13
discovery finds nothingconfirm signals first; harvey discover --providers lists other sources
Claude calls failclaude login, then claude update; harvey status --check tests it
emails land in spamalmost always the domain: check SPF / DKIM / DMARC, halve your volume
